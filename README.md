# SQL — PostgreSQL Coursework

My SQL work from the Bachelor in Data Analytics & AI at EDC Paris Business School (2026), written in PostgreSQL with pgAdmin 4.
It follows the course class by class, from creating tables to window functions.

## What's inside

| Folder | Topics | Data |
|---|---|---|
| `Activities/Class 1` | First queries with `SELECT` | Course sample table |
| `Activities/Class 2` | Creating and changing tables: `CREATE`, `ALTER`, `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE`, `DROP` | Small practice table, plus 10 public datasets for practice (Titanic, Netflix, Spotify, Airbnb…) |
| `Activities/Class 3` | Importing a CSV with `COPY`, filtering with `WHERE`, `AND`/`OR`, `BETWEEN`, `IN`, `LIKE`, `LIMIT` | Goodreads books |
| `Activities/Class 4` | Defining column types and importing multi-file data | Startup funding rounds (Jan–Mar 2020), COVID-19 global statistics |
| `Activities/Class 5` | Joins: `INNER`, `LEFT`, `RIGHT`, `CROSS` | Students and courses |
| `Activities/Class 6` | Subqueries, `GROUP BY` with aggregates, `EXPLAIN`, and window functions: `SUM() OVER`, `PARTITION BY`, `RANK`, `DENSE_RANK`, `ROW_NUMBER` | Products and product groups, sales |

## Tools
PostgreSQL · pgAdmin 4 · Excel / CSV
